Stay Safe

Protect your
computer.

Whether or not a specific allegation is proven, these are good practices whenever you are downloading third-party Gorilla Tag software.

Before running a DLL

  • Only download from sources you trust.
  • Scan unfamiliar files with reputable security tools.
  • Check what the software actually does.
  • Avoid suspicious downloaders or executables.

If something looks suspicious

  • Do not run the file.
  • Keep the original file for analysis if appropriate.
  • Report suspicious software to the relevant platform.
  • Ask trusted developers for a second opinion.
